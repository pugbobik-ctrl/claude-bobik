# Artist names in the DINNER lettering (vector)

Black vector names, one even-odd path per word, cap height = 100 units in every file:
- `<slug>_2line.svg` — first name over surname, left aligned (the main version)
- `<slug>_1line.svg` — on one line
- `<slug>_first.svg`, `<slug>_last.svg` — each word alone
- `all_names.svg` / `all_names.pdf` — all ten lockups in one file, for Illustrator (vector, no images)
- `names_sheet.png` — the names under the DINNER logo for comparison

Built by `../names.py` (recipe and the per-name corrections are in its docstring and PAIRS / OPEN tables):
letters set with optical spacing, one melt over the word with the logo's settings, each letter's
counters carved back, E bays opened toward the next letter as in DINNER.
