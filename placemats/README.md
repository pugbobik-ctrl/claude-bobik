# Подложки под посуду — вектор

Бумажные подложки с фотографии сервировки, переведённые в вектор для печати и резки.

| Файл | Фигура | Размер, мм |
|---|---|---|
| `01-tarelka` | Тарелка | 382 × 318 |
| `02-vilka` | Вилка | 57 × 252 |
| `03-nozh` | Нож | 67 × 274 |
| `04-kremanka` | Креманка | 202 × 171 |
| `05-bokal-flyute` | Бокал-флюте | 218 × 276 |
| `06-lozhka` | Ложка | 109 × 114 |
| `07-zvezda` | Звезда | 187 × 146 |
| `00-raskladka` | Вся сервировка, как на столе | 602 × 900 |

- `svg/` — для Illustrator, Figma или плоттера. `pdf/` — для типографии. Все файлы в натуральную величину.
- **Масштаб оценён по фото:** тарелка взята шириной 380 мм, по размеру мандарина. Если реальная тарелка другого размера, масштабируйте все файлы одинаково, пропорции между фигурами верные.
- Перспектива фото исправлена, формы сняты как будто сверху.
- Все фигуры обведены точно по краю оригинала: край найден по цвету с субпиксельной точностью и переведён в кривые Безье. Вилка и нож выровнены вертикально, у ножа выпрямлен обух (на фото его искажали блики), у звезды грани прямые.
- Цвета подобраны по фото примерно. Сверьте их с бумагой перед печатью.
- У белых фигур (тарелка, звезда) есть тонкий серый контур (`*-outline`), чтобы их было видно и удобно резать. Если он не нужен, удалите его. Серый фон в раскладке не печатается.
- Кольцо на тарелке частично закрыто мандарином. Этот участок достроен плавной кривой.
