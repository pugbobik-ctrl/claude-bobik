# Подложки под посуду — вектор

Бумажные подложки с фотографии сервировки, переведённые в вектор для печати и резки.

| Файл | Фигура | Размер, мм |
|---|---|---|
| `01-tarelka` | Тарелка | 382 × 318 |
| `02-vilka` | Вилка | 57 × 252 |
| `03-nozh` | Нож | 67 × 274 |
| `04-kremanka` | Креманка | 202 × 171 |
| `05-bokal-flyute` | Бокал-флюте | 218 × 276 |
| `06-lozhka` | Ложка | 109 × 114 |
| `07-zvezda` | Звезда | 187 × 146 |
| `00-raskladka` | Вся сервировка, как на столе | 602 × 900 |

- `svg/` — для Illustrator, Figma или плоттера. `pdf/` — для типографии. Все файлы в натуральную величину.
- **Масштаб оценён по фото:** тарелка взята шириной 380 мм, по размеру мандарина. Если реальная тарелка другого размера, масштабируйте все файлы одинаково, пропорции между фигурами верные.
- Перспектива фото исправлена, формы сняты как будто сверху.
- Все фигуры обведены точно по краю оригинала: край найден по цвету с субпиксельной точностью и переведён в кривые Безье. Вилка и нож выровнены вертикально, у ножа выпрямлен обух (на фото его искажали блики), у звезды грани прямые.
- Цвета подобраны по фото примерно. Сверьте их с бумагой перед печатью.
- У белых фигур (тарелка, звезда) есть тонкий серый контур (`*-outline`), чтобы их было видно и удобно резать. Если он не нужен, удалите его. Серый фон в раскладке не печатается.
- Кольцо на тарелке частично закрыто мандарином. Этот участок достроен плавной кривой.

## С фото деревянных предметов (`11`–`16`)

Два ножа, вилка с тёмной ручкой, зелёная ложка, кубок, голубая фигура. Двухцветные предметы состоят из двух контуров, по одному на каждый цвет. Масштаб примерно 0,875 мм на пиксель фото, оценён по грецким орехам и блюдцу эспрессо.

## Новый сервиз — `servis/`

96 предметов в том же стиле, по 2–3 варианта: большие и десертные тарелки, миски, вилки, ножи, ложки (в том числе чайные), бокалы, флюте, креманки, стаканы, чашки, чайники, кувшины, звёзды.

Креативные формы (`39`–`52`): волнистые приборы с ручками из «бусин» и зубцами-волнами, контурные приборы, нарисованные текучей линией, подложка с рисунком сервировки, подложки «Печенье» с фестонным краем, тарелка «Лужица», бокал «Бусы», чашка с волнистой ручкой.

Кофейные (`53`–`57`, `72`–`81`): чашка «Бар» с круглым ушком, стопка чашек, чашка «Облако», кружка с ручкой-цветком, кружка на ножке, гейзерная кофеварка, турка, френч-пресс, кофемолка, зерно, стакан навынос, капучино сверху, чашка с паром, сахар, холдер.

Керамика и декор (`58`–`71`): ваза-амфора, бутылка, ваза-шар, горшок с крышкой, миска с ушками, пиала, тарелка-бублик, кувшин-конус, сливочник, креманка для мороженого, стопка, ромашка, веточка, яблоко.

Пекарня (`82`–`96`): круассан, багет, хлеб, крендель, пончик, маффин, кусок торта, булочка-улитка, печенье, эклер, макарон, пирог, скалка, венчик, поварской колпак.

`servis/obzor.png` — все предметы в одном масштабе; отдельные обзоры: `obzor-kreativ.png`, `obzor-kofe-pekarnya.png`, `obzor-keramika.png`; `servis/catalog.json` — список с размерами.
